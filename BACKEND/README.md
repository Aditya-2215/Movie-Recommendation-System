# Movie Recommendation Backend

FastAPI backend for the content-based movie recommendation system.

## Architecture

```text
HTML / CSS / JavaScript frontend
            |
            | REST API
            v
         FastAPI
        /       \
       /         \
TF-IDF model     TMDB API
   |                 |
   |                 +-- posters
   |                 +-- movie details
   |                 +-- cast / director
   |                 +-- trailer
   |
   +-- tfidf_matrix.pkl
   +-- indices.pkl
   +-- df.pkl
   +-- tfidf.pkl
```

The recommendation calculation is performed locally with your saved TF-IDF matrix and cosine similarity. TMDB is used to enrich search/results with current movie metadata and images.

## 1. Put the model files in `models/`

Copy:

```text
models/
├── tfidf_matrix.pkl
├── indices.pkl
├── df.pkl
└── tfidf.pkl
```

These should be the exact files generated by your notebook.

## 2. Create the environment

Windows:

```powershell
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

## 3. Add TMDB key

Copy `.env.example` to `.env` and put your key in:

```env
TMDB_API_KEY=YOUR_KEY_HERE
```

Do not put this key in `frontend/app.js`.

## 4. Start FastAPI

```powershell
uvicorn main:app --reload --host 127.0.0.1 --port 8000
```

Open:

- API: http://127.0.0.1:8000
- Swagger: http://127.0.0.1:8000/docs
- ReDoc: http://127.0.0.1:8000/redoc

## API endpoints

### Health

```http
GET /api/health
```

### Search

```http
GET /api/search?q=Inception&limit=10
```

### Recommendations

```http
GET /api/recommend?title=Inception&n=10
```

Disable TMDB enrichment if needed:

```http
GET /api/recommend?title=Inception&n=10&enrich_tmdb=false
```

### TMDB movie details

```http
GET /api/movie/27205
```

## Important

The `id` column in `movies_metadata.csv` is normally the TMDB movie ID. If your `df.pkl` still contains this column, the backend uses it to enrich recommendations directly from TMDB. If it is missing, the backend falls back to a TMDB title search.

## Notes about your current ML pipeline

Your notebook uses:

```text
overview + genres + tagline
        -> preprocessing
        -> TF-IDF
        -> cosine similarity
        -> recommendations
```

This backend does not silently replace that model. It loads the saved artifacts and uses them for recommendation generation.
